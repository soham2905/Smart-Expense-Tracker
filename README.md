# Smart-Expense-Tracker
The Problem:
Students and young earners spend money every day — on food, travel, shopping — but rarely track it. By the end of the month, they don't know where their money went. Apps like CRED or Walnut are too complicated for this simple need — they're built for credit cards and investments, not everyday pocket money tracking.

Our Solution:
We built a simple web app where you can:

Add an expense — just type what you spent, how much, and pick a category.
See your spending — the dashboard instantly shows how much you spent today, this week, and this month.
Understand your habits — a breakdown shows which category (Food, Travel, Bills, etc.) is eating up your money.
Get warned — if you cross your monthly budget, the app shows a red alert automatically.
Edit or delete any expense anytime.

Why it's useful:

No login, no confusion — anyone can use it in under a minute.
Answers one simple question every student asks: "Where did my money go?"
Helps build good money habits early, before overspending becomes a real problem.

How we built it:

Backend: Java + Spring Boot (handles the logic)
Frontend: Simple HTML pages styled with Bootstrap (no JavaScript at all — everything works with plain page loads)
Database: H2 (stores all expense records)
